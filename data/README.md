# Data Folder

This folder stores all past content samples and historical data from TRO's marketing campaigns.

## Structure

### Reels Scripts
- Store Instagram and YouTube reel scripts
- Include performance metrics (views, engagement)
- Note storytelling patterns and hooks used

### Captions
- Social media captions for different platforms
- Categorized by client/campaign
- Include hashtag strategies

### Campaign Ideas
- Brainstormed campaign concepts
- Seasonal/trending content ideas
- Client-specific strategies

### Client Strategies
- Nature's Cafe marketing approach
- The Legit Talks content style
- My Earth campaign themes
- Crackpot brand voice
- Other client documentation

### Case Studies
- Successful campaign breakdowns
- What worked and why
- Lessons learned
- ROI and engagement metrics

## How to Add Content

1. Create subfolders for each content type
2. Use clear naming: `client-name_content-type_date.txt`
3. Include metadata in files (date, platform, performance)
4. Keep original content intact for AI learning

## Example File Structure
```
/data
  /reels_scripts
    natures-cafe_smoothie-launch_2026-01-15.txt
    the-legit-talks_interview-promo_2026-01-20.txt
  /captions
    my-earth_sustainability_2026-02-01.txt
  /campaign_ideas
    seasonal_valentine-2026.txt
  /client_strategies
    natures-cafe_brand-voice.md
  /case_studies
    viral-reel-analysis_jan-2026.md
```
