# TRO AI Prompts Library

Reusable AI prompts for generating content in TRO style.

## Reel Ideas Generator

### Prompt Template
```
You are a creative content strategist for The Real Ones (TRO), a marketing agency. 
Generate 10 Instagram reel ideas about [TOPIC] that:
- Hook viewers in the first 3 seconds
- Are educational yet entertaining
- Showcase expertise without being salesy
- Include a clear call-to-action
- Match TRO's energetic, professional, and conversational tone

Format: Provide hook, main content points, and CTA for each idea.
```

### Example Usage
Replace [TOPIC] with:
- "Content marketing for small businesses"
- "Social media trends in 2026"
- "Behind-the-scenes of a marketing campaign"

## Caption Writer

### Instagram Caption Prompt
```
Write an Instagram caption for The Real Ones (TRO) about [TOPIC/POST DESCRIPTION].

Style requirements:
- Start with a hook that stops scrolling
- Conversational and relatable tone
- Include storytelling or personal insight
- 150-200 words optimal length
- End with a question or call-to-action
- Include 5-8 relevant hashtags
- Use emojis sparingly but strategically

TRO voice: Energetic, professional yet friendly, results-focused, authentic
```

### LinkedIn Caption Prompt
```
Write a LinkedIn post for The Real Ones (TRO) about [TOPIC].

Style requirements:
- Professional yet conversational
- Lead with value or insight
- Include a personal story or client success
- 200-300 words
- Break into short paragraphs for readability
- End with a thought-provoking question
- No hashtags or minimal professional hashtags only

TRO voice: Thought leader, results-driven, authentic, helpful
```

## Content Calendar Generator

### Monthly Content Calendar Prompt
```
Create a 30-day content calendar for The Real Ones (TRO) focusing on [THEME/CLIENT].

Include:
- Mix of content types: educational, behind-the-scenes, client stories, trending topics
- Platform-specific content (Instagram, LinkedIn, Facebook)
- Content themes: Mondays (Motivation), Wednesdays (Education), Fridays (Fun/BTS)
- Seasonal/trending hooks where relevant
- Balance between promotional and value-driven content (80/20 rule)

For each day provide:
1. Content type
2. Topic/angle
3. Brief description
4. Platform
5. Key message
```

## Video Script Writer

### Short-Form Video Script
```
Write a 30-60 second video script for TRO about [TOPIC].

Structure:
- Hook (0-3 sec): Attention-grabbing question or statement
- Problem/Context (4-15 sec): What issue are we addressing?
- Solution/Value (16-45 sec): Main content, tips, insights
- CTA (46-60 sec): What should viewers do next?

Style:
- Conversational and direct
- Fast-paced, energetic delivery
- Visual cues noted in [brackets]
- Text overlays suggested in (parentheses)
- TRO branding elements

Format: Include exact narration + visual directions
```

## Storytelling Enhancer

### Story Amplification Prompt
```
Take this basic message: [INSERT BASIC MESSAGE/FACT]

Transform it into a compelling story using TRO's storytelling framework:

1. Personal Connection: How does this relate to real people?
2. Challenge/Obstacle: What problem does this solve?
3. Journey: What's the transformation process?
4. Result/Impact: What changed? What was achieved?
5. Lesson/Takeaway: What can others learn?

Make it:
- Emotionally resonant
- Authentic and specific
- Visually descriptive
- Actionable for the audience

Length: 250-400 words
```

## Usage Instructions

1. **Copy the prompt template**
2. **Replace [BRACKETED SECTIONS] with specific information**
3. **Paste into your AI tool** (ChatGPT, Claude, Perplexity, etc.)
4. **Review and refine output** to match TRO's exact voice
5. **Save successful variations** back to this library

## Tips for Better Results

- Be specific in your [TOPIC] replacements
- Provide context about the client or campaign
- Include any specific requirements or constraints
- Reference past successful content when relevant
- Iterate: Generate multiple options and pick the best
- Always add human touch and TRO personality to AI output

## Customization

Feel free to mix and match elements from different prompts or create hybrid prompts for specific needs. The key is maintaining TRO's authentic voice while leveraging AI efficiency.
